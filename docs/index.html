How to Play

👆

Tap to Fly

Tap the screen to make the bird flap its wings and fly upward

🚧

Avoid Pipes

Navigate through the gaps between the pipes without hitting them

🏆

Score Points

Each pipe you pass earns you a point. How far can you go?

How to Install

1

Download the APK

Tap the green "Download APK" button above. Your phone will download a file called game.apk.

2

Allow Unknown Apps

If prompted, go to Settings → Security → Install unknown apps and enable it for your browser.

3

Open & Install

Tap the downloaded game.apk file from your notifications or file manager, then tap "Install".

4

Play! 🎮

Open FlopyBird from your app drawer and start playing. Tap to fly!
